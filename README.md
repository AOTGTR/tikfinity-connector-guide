# avotik — ตั้งค่าให้ TikFinity เชื่อมต่อได้

คู่มือภาษาไทย: เปิดเมนู avotik ในเกมด้วย Shift ขวา แล้วตั้ง IP / Port / รหัส ให้ TikFinity ต่อเข้า Minecraft

**อ่านคู่มือ:** https://aotgtr.github.io/tikfinity-connector-guide/

## ในคู่มือมีอะไร

- เปิดเมนู avotik 3 ทาง: Shift ขวา · `/avotik` · Mod Menu
- ในเมนูมีอะไรบ้าง และปุ่มคืนค่าเริ่มต้นใช้ตอนไหน
- ตั้งค่าเมื่อ TikFinity อยู่เครื่องเดียวกัน / คนละเครื่อง
- ใช้ตอนเล่นในเซิร์ฟเวอร์ (เซิร์ฟไม่ต้องลงมอด ขอแค่มี op) และทางเลือกลงมอดที่เซิร์ฟ
- คำสั่ง `/avotik` · เปิด firewall · ความปลอดภัย · แก้ปัญหา

## ไฟล์

- `index.html` — ตัวคู่มือ (หน้าเดียว)
- `assets/` — ภาพประกอบ

หน้าเว็บ deploy ผ่าน GitHub Pages จาก branch `main`
